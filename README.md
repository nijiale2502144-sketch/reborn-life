# 轮回人生录 · 可玩原型（MVP）

按策划案做的可玩版本，目前有四个人生剧本：《麦田上的誓言》（农夫之子 → 圣骑士），《灰烬中的家徽》（没落贵族 → 大魔法师），《暗巷里的钥匙》（街头孤儿 → 影子之王），《远海的星图》（码头学徒 → 传说船长）。能从开局玩到结局、结算转生点、在转生树里花掉，再开下一世。

## 运行

浏览器只能通过 HTTP 加载 ES 模块，所以需要起一个静态服务器，根目录要选 `pixel-assets/`（游戏要读 `../scenes` 和 `../portraits` 里的素材）：

```bash
cd pixel-assets
python3 -m http.server 8765
```

然后打开 <http://127.0.0.1:8765/game/index.html>。键盘：数字键选项，`Enter` 继续，`E` 结束回合。存档在浏览器 localStorage（局内每一步自动存，局外转生点单独存）。

命令行（需要 Node 18+，无需 npm install）：

```bash
cd pixel-assets/game
npm run lint      # 检查内容：引用的事件/任务/物品是否存在，条件和效果语法是否正确
npm run sim       # 无界面模拟 1000 局，输出通关率、转生点分布、结局分布
npm test          # lint + 两个机器人各跑 200 局，确认没有死循环和报错
node sim/simulate.js --bot balanced --runs 500 --progress   # 连续玩并自动买转生树，看局外成长曲线
```

机器人可选 `balanced`（均衡）、`fighter`（只刷地下城）、`farmer`（只种田）、`random`（乱点）。

## 目录

```
game/
  index.html, style.css
  src/
    engine.js    规则引擎：回合、体力、事件、任务、地下城、战斗、结局（无 DOM，无 Node 依赖）
    cond.js      条件语法（&& 与，数组为或）
    score.js     转生点结算
    meta.js      转生树、天赋、图鉴、结算入账
    content.js   内容加载器
    ui.js        界面（只负责画 state.prompt）
  content/       全部内容，都是 JSON，策划可以直接改
    config.json  全局数值（体力、成长、概率）
    common/      通用行动和通用事件
    farmer_son/  剧本：script（出身/年终/结局/志向）、actions、events、quests
    dungeons.json  enemies.json  items.json  meta.json
  sim/           机器人与模拟器
  tests/lint.mjs 内容检查
```

## 怎么加内容

- **加一个行动**：在 `content/<剧本>/actions.json` 加一项。`fx` 是必得效果，`check` + `ok/fail/great` 是带检定的分支，`cond` 控制何时出现。
- **加一个事件**：事件按类型分文件放在 `content/farmer_son/` 下（`events.json` 主线与剧情节点、`events_random.json` 随机与条件叙事、`events_derived.json` 行动衍生、`events_story.json` 剧情与人物线、`events_dungeon.json` 地下城事件；通用的在 `content/common/`），新增文件要在 `src/content.js` 登记。`kind` 取 `random`（回合开始抽取）、`special`（按 `when` 年龄季节或 `cond` 触发）、`derived`（做某个行动后有 8% 概率追加，写 `parent`）、`chain`（只能被 `goto:` 调用）、`dungeon`（地下城事件节点，可用 `dungeons:["cave"]` 限定地下城）。条件里不支持 `||`，要写成数组（或），`npm run lint` 会检查。
- **加一个任务**：在 `quests.json` 加一项，每个阶段写 `done` 条件，可带 `deadlineAge` / `deadlineTurns` / `onMiss`。
- 条件和效果的写法见 `src/cond.js` 和 `src/engine.js` 里 `fx()` 上方的注释。改完先跑 `npm run lint`。
- **加一个剧本**：新建 `content/<新剧本>/` 四个文件，在 `src/content.js` 里登记，在 `ui.js` 的 `boot()` 里按剧本 id 创建引擎即可，引擎不用改。

## 魔力与技能

- 魔力上限 = 意志 × 2 + 智力。每回合自然恢复 25%，「休息」行动和地下城休息点可回魔（休息点恢复 30%）。
- 战斗里除了强攻、稳守、撤退，学会的技能也是战术选项。技能写在 `content/skills.json`：`mp` 消耗、`win` 胜率加成、`vs` 对某类敌人再加成（敌人标签：野兽 / 亡灵 / 魔族 / 人类）、`injure` 落败时受伤倍率、`heal` 立刻回血比例。
- 学习方式写在剧本 `script.json` 的 `autoLearn`（条件满足就自动习得），也可以在事件或行动里用 `learn:技能id`。计数用 `count:名字+1`，条件里用 `count.名字>=3`。
- 目前的路线：

| 路线 | 技能 | 怎么学 |
| --- | --- | --- |
| 武技（无消耗） | 破绽斩、格挡反击、老兵绝技 | 向格伦学艺；老兵绝技要为格伦翻案 |
| 圣光 | 治愈之光、圣光斩、圣盾 | 帮神父打杂，累计次数加教会声望；圣盾要先成为修士 |
| 魔法 | 魔法飞弹、火球术、魔力护盾 | 先得到一本法术书（路过的老法师、旧书摊、读书时翻到夹层），再「研读奥术」；魔法威力随智力成长 |

- 旧存档继续游戏时会自动补上魔力等新字段（`g.migrate`）。

几点观察，调数值时需要注意：
- 每次增加成长、金币或技能相关的内容，都要重新跑模拟：金币有了出口（雇短工、集市、修水车）之后，balanced 一度升到 64%，把短工价格提到 60 金币、敌人战力上调约 3% 才回到 53%。
- 修了一个 Bug：之前输给地下城 Boss 也会被算作通关（并拿到首通奖励和 Boss 通关的文案）。现在输了会被打出来（“败退”），拿不到通关奖励，之前一路上得到的金币和经验保留。
- 体魄仍然最划算，智力优先的魔法师通关率 36%，已经可玩。
- 真人新手不会像 balanced 那样每回合最优，策划案里“前 3 局基本通不了”的目标大概率能满足。
- 实际一局约 56 回合就结束了（魔王 30 岁秋天苏醒，4 回合内决战）。

## v0.3 更新：第二个剧本与存档

### 《灰烬中的家徽》

- **设定：** 没落的格雷蒙特伯爵家，16 岁开局，背着 600 金币的债。五年前父亲被控叛国，宰相洛克伍德主审。下一次「旧案复议日」在 28 岁的秋天，是唯一翻案的机会。
- **和《麦田上的誓言》的差别：**
  - 体魄低、智力和魅力高，体力上限从 5 起步；不能种地，靠家教、誊写、变卖旧物挣钱。
  - 「故乡值」换成「家族名望」，并多出三个关键数值：债务（每年利息 +40）、证据、盟友，都显示在顶栏或侧栏。
  - 魔法为主路线：研读奥术、旁听高塔讲座、高塔声望，三次晋升考核（学徒 / 初级 / 中级魔法师）。新增 3 个魔法技能：冰锥术、奥术洪流、时缓术。
  - 终局是 28 岁秋天的复议日：出示证据呈堂、向宰相决斗，或者放下一切。六个结局，包括「家徽重燃」（真结局）。
- **内容量：** 94 个事件、7 个任务（主线 5 章 + 6 条支线：母亲的药、老管家的秘密、墨提斯的三道题、艾琳的线索、宿敌瓦伦、清偿债务）、26 个行动。
- **美术：** 7 张新人物立绘（含母亲、老管家、导师墨提斯、艾琳、瓦伦、宰相）和 7 张新场景（旧宅四季、高塔、图书馆、王都街道、法庭），仍是占位像素图，由 `gen_pixel2.py` 生成。

### 存档的导出与导入

- 顶栏的「存档」按钮（标题页是「存档管理」）可以生成一段存档代码，包含转生点、已解锁内容和进行中的这一世。
- 在线版（Artifact）里浏览器经常拦截文件下载，所以主要靠「复制存档代码」和「粘贴导入」；离线单文件和本地服务器版也可以用「下载为文件」和「选择文件」。
- 导入前会检查格式和剧本是否存在，并且要点两次才会覆盖当前进度。存档代码以 `REBORN1Z:`（压缩）或 `REBORN1:` 开头。

### 引擎和内容结构的变化

- `content/scripts.json` 登记所有剧本；每个剧本一个文件夹，结构相同。
- 剧本可以用 `labels`、`help`、`tips` 覆盖通用文案（比如把「故乡值」改叫「家族名望」），用 `display` 增加要在界面上展示的计数器，用 `clearCond` 定义什么算通关，用 `scenes` 指定各季节的默认背景，用 `unlockCost` 设置解锁价格。
- 通用事件和行动加 `only:["剧本id"]` 就只在该剧本出现；地下城行动可以用 `dungeonName` 改名。
- 修了一个会卡死的 Bug：事件弹出后，如果条件变化使所有选项都不可选，现在会给一个「继续」兜底。

## v0.4 更新：遗物、命运阶位，第二个剧本补充事件

### 遗物（传承）

- 开局可以携带一件遗物，由成就解锁，不能用转生点购买。一局结束时，满足条件就会解锁，并在结算页提示。
- 写在 `content/meta.json` 的 `relics`：`unlock.cond` 是解锁条件（可用 `ending==结局id`、`flag:`、`quest.xxx==done` 等，按这一局结束时的状态判断），`script` 限定剧本，`start` 是开局给的东西（装备、标记、计数、声望、好感、金币、故乡值、属性），`mods` 是持续加成（战力、魔力上限、濒死次数、起始幸运等）。
- 目前 11 件：先祖的镰刀、圣徽残片、老兵的酒壶、褪色的推荐信、魔王的碎角、洛恩的车轮（农夫）；白玫瑰胸针、父亲的旧信、墨提斯的怀表、艾琳的书签（贵族）；幸运硬币（通用）。
- 每件遗物把通关率拉高约 5 到 9 个百分点，定位是“让后续的周目更顺手”，不是数值碾压。

### 命运阶位

- 首次通关任意剧本后解锁。在当前最高阶位通关，解锁下一阶，最高 5 阶。每提高一阶叠加一条规则，转生点收益 +20%（v0.5 起重新排布，让难度平滑上升）：
  1. 灾厄类随机事件的权重 +20%，支线任务的期限提前 1 年，敌人战力 +0.6%。
  2. 敌人战力共 +1.2%，落败时受到的伤害 +3%。
  3. 终局提前 1 年到来（魔王苏醒、复议日）。
  4. 敌人战力共 +1.8%，落败时受到的伤害共 +8%。
  5. 敌人战力共 +2.4%，主线任务的期限提前 1 年，濒死判定的难度 +2。
- 贵族剧本在第 3 阶额外有债务每年涨 20 金币利息、查案类检定难度提高（`script.fateRules` 覆盖文案）。
- 在设置页选择阶位，侧栏会显示当前阶位和规则。终局事件要写 `finale:true` 才会随阶位提前。
- 模拟里（均衡机器人，各 600 局）通关率：农夫 54 → 45 → 42 → 30 → 24 → 19%（阶位 0 到 5），贵族 57 → 49 → 45 → 40 → 35 → 26%；平均转生点随阶位上升（农夫 661 → 912）。曾经的“阶位 3 体力 -1”和“阶位 4 濒死只有 1 次”都是断崖，已移除。注意：敌人战力每 +1% 的影响比想象中大（约 -3 到 -4 个百分点），调整时请用小步长。

## v0.5 更新：战力、装备、集市与风险

- **战力公式：** 等级×4 + 主属性（体魄/智力/意志中最高）×1.5 + 另两项×0.5 + 装备 + 加成。敏捷：落败时减伤（每点高于 8 的部分 -1.2%，上限 40%）；幸运：每点高于 10 的部分让检定和战斗成功率 +0.5%；魅力：决定能进入哪一档“贵客集市”。
- **装备槽：** 武器 1、护甲 1、盾牌 1、饰品 2，同槽只有最强的生效。新增三档装备（钢/精钢/秘银，水晶/大法师/星辰等），农夫剧本的集市“贵客区”按魅力 10/14/18 解锁，贵族剧本同理。地下城战利品也升级了。
- **地下城风险：** 战力 48/92/129/169（层数 4/5/6/7），落败伤害 ×0.55、Boss 层再 ×1.25、濒死难度 11。收益仍高于种地（每点体力：要塞约 27 金币，种秋收约 12.5），但死亡率约 13%，需要权衡。
- **帮工：** 价格在一年内递增（60/80/110/150），年初重置；年金已取消。
- **水车：** 修好之后永久把故乡值每年衰减从 -5 降到 -3。
- **技能进度：** 未学会的技能显示学习条件的完成情况（✓/○ 和当前值）；圣盾去掉了祈祷次数要求，改为“成为修士且教会声望 ≥ 60”。

## v0.6 更新：隐藏任务「教会的阴影」与记忆碎片

## v0.9.2 更新：支线任务的随机性

- **变故（`snag`）：** 大部分支线开启时，会暗中掷一次骰子（幸运每高于 10 一点，概率降低 1%）。掷中的任务会在 1 到 6 回合之内因意外而失败（NPC 离开、线索断掉、东西丢了……，每条任务有各自的文案），走任务自己的失败结果。概率按任务 20% 到 45% 不等；没有加变故的有：主线、隐藏任务，以及关系到真结局或主线条件的任务（艾芙娜的心愿、母亲的药、红鲨的挑战、人鱼的歌）。
- **期限抖动：** 每个有期限的支线，每局还会有 -1、0、0、+1 年的随机偏移，任务面板上显示的是抖动后的期限。
